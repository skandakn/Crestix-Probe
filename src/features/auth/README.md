# Auth Feature Module

- **Owner**: Auth Team
- **Routes**: `/login`, `/register`
- **Scope**:
  - Mission operator authentication & multi-factor verification
  - Role-based clearance levels (Commander, Engineer, Specialist, Viewer)
  - Ground station authorization token refresh
- **Contracts**:
  - Use UI components from `@/components/ui` (`Input`, `Button`, `Card`)
  - Endpoints: `/api/auth/login`, `/api/auth/register`, `/api/auth/me`
